# منظومة الفجيرة للوعي والتمكين المالي — نموذج تفاعلي (Interactive Executive Prototype)

نموذج عرض تفاعلي كامل (Frontend Demo) لمنصة رقمية وتدريبية للوعي المالي على مستوى إمارة الفجيرة.
لا يوجد Backend ولا قاعدة بيانات ولا تسجيل دخول فعلي — جميع البيانات تجريبية ومحفوظة في ملفات داخل المشروع.

> **تنويه:** جميع الأسماء والمدارس والأرقام المعروضة تجريبية وغير حقيقية، ولا تمثل بيانات حكومية رسمية.
> الشعار المستخدم عنصر توضيحي بديل (Placeholder) وليس شعاراً رسمياً.

## التشغيل محلياً

```bash
npm install
npm run dev
# http://localhost:3000
```

بناء نسخة الإنتاج:

```bash
npm run build && npm run start
```

## التقنيات

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS 3 — نظام تصميم مخصص (كحلي / ذهبي / أبيض رملي)
- lucide-react للأيقونات، Recharts للرسوم البيانية
- RTL كامل على مستوى الـLayout، خط Tajawal
- حالة التجربة محفوظة في `localStorage` فقط

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | الصفحة الرئيسية |
| `/demo` | استعرض التجربة — 8 شخصيات تجريبية للدخول المباشر |
| `/assessment` | قياس المستوى المالي (تقييم تفاعلي يختلف حسب الفئة) |
| `/dashboard` | منصة المستفيد (لوحة شخصية) |
| `/schools` | المدارس المشاركة |
| `/school/[id]` | لوحة أداء مدرسة |
| `/paths` | المسارات التعليمية العشرة |
| `/path/[id]` | صفحة مسار مع الوحدات التعليمية |
| `/training` | البرامج التدريبية الحضورية + الأهلية |
| `/rewards` | المكافآت والنقاط والشارات |
| `/impact` | قياس الأثر (قبل / بعد) |
| `/executive` | لوحة المؤشرات التنفيذية |

## بنية البيانات التجريبية

```
src/data/
  users.ts        8 شخصيات بنتائج ومسارات مختلفة
  schools.ts      8 مدارس ببيانات أداء وصفوف
  paths.ts        4 مستويات مدرسية + 6 مسارات للبالغين + الوحدات
  training.ts     8 برامج تدريبية في الفجيرة ودبي وأبوظبي
  badges.ts       8 شارات مرتبطة بإنجاز محدد
  rewards.ts      5 مستويات مكافآت
  assessment.ts   بنكا أسئلة (طلبة / بالغون) ومنطق النتيجة
  executive.ts    مؤشرات ولوحات المستوى التنفيذي
```

## ما يحتاجه المشروع من ملفات أصلية

- شعار حكومة الفجيرة وشعار البرنامج بصيغة SVG أو PNG شفافة
- صور فوتوغرافية عالية الدقة: مشاهد الفجيرة، طلبة، ورش تدريبية
- اعتماد نصوص المحتوى النهائية من فريق البرنامج
