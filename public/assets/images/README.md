# الصور

الصور الحالية **مؤقتة** (`.svg`) وأُنشئت خصيصاً لهذا النموذج لتكون منظمة ومتسقة
مع الهوية البصرية إلى حين توفر الصور الفوتوغرافية الرسمية.

- `fujairah/` — صور الإمارة: الساحل، جبال الحجر، المعالم، الطبيعة.
- `students/` — صور طلبة المدارس وبيئات التعلّم.
- `beneficiaries/` — صور المستفيدين: الجامعة، الموظفون، الأسر، كبار السن، الورش.

راجع `public/assets/README.md` لجدول الأسماء والمقاسات.
