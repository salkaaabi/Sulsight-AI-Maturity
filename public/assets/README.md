# مجلد الأصول البصرية — assets

هنا تُرفع الملفات الرسمية (الشعارات والصور). الصور الحالية **مؤقتة** بصيغة `.svg`
ويُستبدل أي منها بمجرد وضع ملف رسمي بنفس الاسم الأساسي — **دون أي تعديل في الكود**.

```
public/assets/
├── logos/                       ← الشعارات الرسمية
│   ├── fujairah-government-logo.svg   ← ضع هنا شعار حكومة الفجيرة
│   └── programme-logo.svg             ← ضع هنا شعار المنظومة (اختياري)
│
└── images/
    ├── fujairah/                ← صور الإمارة ومعالمها وطبيعتها
    │   └── hero-main.jpg              ← صورة الواجهة الرئيسية (Hero)
    │
    ├── students/                ← صور طلبة المدارس
    │   ├── students-school.jpg        ← بطاقة «المرحلة الأولى»
    │   └── classroom.jpg              ← صفحات المسارات المدرسية
    │
    └── beneficiaries/           ← صور المستفيدين من الفئات المختلفة
        ├── adults-city.jpg            ← بطاقة «المرحلة الثانية»
        ├── training-workshop.jpg      ← البرامج التدريبية الحضورية
        └── advisor-session.jpg        ← قسم الاستشارة المالية
```

## كيف أستبدل صورة؟

1. جهّز الصورة بالمقاس الموصى به (مذكور في الجدول أدناه).
2. سمِّها بالاسم الأساسي المذكور أعلاه.
3. ضعها في مجلدها بامتداد `.jpg` أو `.png` أو `.webp`.
4. أعد تحميل الصفحة — ستظهر تلقائياً وتختفي علامة «صورة مؤقتة».

| الموضع | المسار | الاسم | النسبة والمقاس |
|---|---|---|---|
| واجهة الصفحة الرئيسية | `images/fujairah/` | `hero-main` | 16:9 — 2560×1440 |
| بطاقة المرحلة الأولى | `images/students/` | `students-school` | 21:9 — 2100×900 |
| بطاقة المرحلة الثانية | `images/beneficiaries/` | `adults-city` | 21:9 — 2100×900 |
| صفحات المسارات المدرسية | `images/students/` | `classroom` | 4:3 — 1600×1200 |
| مسارات المرحلة الثانية | `images/beneficiaries/` | `training-workshop` | 4:3 — 1600×1200 |
| صفحة الاستشارة | `images/beneficiaries/` | `advisor-session` | 4:3 — 1600×1200 |
| الاستشارة بالرئيسية | `images/beneficiaries/` | `advisor-home` | 1:1 — 1400×1400 |

> **مهم:** النسب أعلاه مقيسة فعلياً من الصفحة. التفاصيل الكاملة وقواعد التكوين
> و`object-position` لكل موضع في `public/assets/IMAGE-BRIEF.md`.

## كيف أستبدل الشعار؟

ضع ملف الشعار الرسمي في `public/assets/logos/` باسم:

- `fujairah-government-logo.svg` — أو `.png` بخلفية شفافة
- `programme-logo.svg` — شعار المنظومة إن وُجد

يظهر الشعار فوراً في الترويسة والتذييل وشريط الجهة المشرفة في الصفحة الرئيسية.
قبل رفعه يظهر إطار بديل نظيف — **لم يُنشأ أي شعار وهمي أو مقلَّد**.

> مرجع الكود: `src/lib/assets.ts` — جميع المسارات معرّفة في مكان واحد.
